# LANFile

LANFile is a simple to use file sharing application, acting as a Web server to upload and download files to.

It's designed to be simple, has the ability to upload and download files via CLI or the Web UI, and is designed to be used on a local network.

Currently, there is no plan for users, however authorisation to overwrite files is planned via key and password

Features:
- [x] Upload files via CLI
- [x] Upload files via Web UI
- [x] Download files via CLI
- [x] Download files via Web UI
- [x] Encryption and decryption of files via password via Web UI
- [x] Easy to use via GPG, encryption and decryption of files via GPG via CLI
- [ ] Authorisation to overwrite files via key and password
- [ ] A pastebin style feature to share snippets accessible via CLI and WEB UI
