# LANFile

LANFile is a simple to use file sharing application, acting as a Web server to upload and download files to.

It's designed to be simple, has the ability to upload and download files via CLI or the Web UI, and is designed to be used on a local network.

Currently, there is no plan for authentication or users, however encryption via passwords and gpg is planned.

Features:
- [ ] Upload files via Web UI
- [ ] Upload files via CLI
- [ ] Download files via Web UI
- [ ] Download files via CLI
- [ ] Encryption of files
